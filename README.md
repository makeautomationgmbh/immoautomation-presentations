# immoautomation Presentations

Marketing presentations, newsletters, and collateral for immoautomation. Use Claude Code here — the `CLAUDE.md` has everything needed (design system, product info, copy bank, slide templates).

## Quick Start

1. `cd` into this repo
2. Open Claude Code
3. Ask for a presentation — Claude has all brand context

## Structure

```
presentations/   — Slide decks (HTML, self-contained)
newsletters/     — Email templates
gallery/         — Image galleries
assets/          — Logos and brand assets
```

## Workflow

- Work on `main` directly for simple additions, or use short-lived branches (`presentation/name`, `newsletter/name`)
- Slides are self-contained HTML files — no build tools needed
- Open any `.html` file in a browser to view
