CLAUDE.md

Das Gehirn des Systems

Eine Datei im Repo, die Claude alles erklärt: Farben, Fonts, Layouts, Produktinfos, Preise und Sprache. Claude liest sie automatisch.

Claude kennt immoautomation bereits vollständig.
03

Claude Code

Die KI, die die Arbeit erledigt

Die App auf eurem Mac. Ihr beschreibt, was ihr braucht — Claude liest CLAUDE.md, schreibt die HTML-Datei und speichert sie direkt im Repo.

Ergebnis: eine fertige .html Datei im Repo

Der Workflow — Teil 1

Von der Idee
zum Prompt.
Schritt 1

Claude Code öffnen

App auf dem Mac starten. Über File → Open Folder den Ordner immoautomation-presentations öffnen.

Schritt 2

Prompt eingeben

Im Chat einfach beschreiben, was ihr braucht. Claude liest automatisch die CLAUDE.md und kennt bereits das komplette immoautomation Design-System.

Schritt 3

Claude arbeitet

Claude liest CLAUDE.md, erstellt die HTML-Datei und legt sie im richtigen Ordner ab. Ihr seht in Echtzeit, was passiert.

Dauert typisch 1–3 Minuten
Wichtig: Den Ordner immoautomation-presentations in Claude Code öffnen — nicht einen Unterordner. So findet Claude die CLAUDE.md automatisch.

Der Workflow — Teil 2

Anschauen,
anpassen, fertig.
Schritt 4

HTML-Datei öffnen

Die fertige .html Datei im Finder doppelklicken. Sie öffnet direkt im Browser — kein Build-Tool, kein Server nötig.

Pfeiltasten zum Navigieren  ·  F für Vollbild
Schritt 5

Feedback geben

Einfach im Chat sagen was geändert werden soll. Claude passt die Datei direkt an — Browser neu laden, fertig.

"Mach Slide 3 kompakter" · "Füge eine Pricing-Slide hinzu" · "Ändere die Headline auf..."
Fertig

Präsentation bereit

Die HTML-Datei ist selbstständig — einfach als Anhang verschicken oder direkt im Browser präsentieren.

Keine Abhängigkeiten, läuft überall
Schritte 4 & 5 beliebig oft wiederholen bis die Präsentation perfekt ist.

Prompt-Tipps

Der perfekte
Prompt.

Vorlage

// Kopiert diese Vorlage und füllt sie aus

Erstell mir eine Präsentation für
[Thema / Anlass].

Zielgruppe: [Wer sieht sie?]
Slides: [Anzahl, z.B. 6–8]

Inhalt:
- [Punkt 1]
- [Punkt 2]
- [Punkt 3]

Sprache: Deutsch
// Design macht Claude automatisch

Das macht Claude besser

Thema und Zweck nennen — "Kundenpräsentation für Makler" vs. "Präsentation"
Zielgruppe angeben — "für Makler die onOffice nutzen"
Slidezahl nennen — "6 bis 8 Slides"
Konkrete Punkte auflisten — was soll auf welcher Slide stehen

Lieber vermeiden

Zu vage: "Mach mir eine gute Präsentation"
Design selbst beschreiben — Claude kennt unser Design-System bereits
Ungeduldig sein — 1–3 Minuten Wartezeit ist normal
